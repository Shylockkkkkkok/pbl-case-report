## 选型

1. 全部为 16:9。
2. 临床/基础医学学术汇报 → `飞上云霄.pptx`（干净，蓝色不抢临床图片）。
3. 正式开题、毕业答辩 → `西安交通大学汇报答辩通用模板.pptx`（校红、版式全，体积 44MB）。
4. 工科/创新港相关 → `2022 西安交通大学创新港风格模板.pptx`。
5. **没有默认模板**，每次按主题选并说明理由。

## 用法

不要只把模板当背景图。正确做法：

1. 直接以模板文件为底稿打开并另存。
2. 保留模板的**封面页**和**结尾页**，只替换文字（含组合形状里的文字要递归遍历）。
3. 内容页用模板的 `空白` / `1_空白` 版式新建 —— 这些版式自带校徽和页眉线，不要再自己贴 logo。
4. 配色用模板主题色，不要混入无关色系。
5. 换过页序后，参考文献编号必须重新按**首次引用顺序**编号（见 SKILL.md）。
