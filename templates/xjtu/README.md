## 选型

1. 默认 16:9。4:3 的三套只在老师明确要求时使用。
2. 医学 PBL / 课程汇报 → `飞上云霄.pptx`（轻、干净、蓝色不抢内容）。
3. 正式开题、毕业答辩 → `西安交通大学汇报答辩通用模板.pptx`（校红、版式全，但体积大）。
4. 需要更强"创新港"主题 → `2022 西安交通大学创新港风格模板.pptx`。

## 用法

不要只把模板当背景图。正确做法：

1. 直接以模板文件为底稿打开并另存。
2. 保留模板的**封面页**和**结尾页**，只替换文字（含组合形状里的文字要递归遍历）。
3. 内容页用模板的 `空白` / `1_空白` 版式新建 —— 这些版式自带校徽和页眉线，不要再自己贴 logo。
4. 配色用模板主题色，不要混入无关色系。
5. 换过页序后，参考文献编号必须重新按**首次引用顺序**编号（见 SKILL.md）。
